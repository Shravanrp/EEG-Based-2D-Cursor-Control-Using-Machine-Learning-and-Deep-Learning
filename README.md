# EEG-Based-2D-Cursor-Control-Using-Machine-Learning-and-Deep-Learning
Developed an EEG-based BCI system for 2D cursor displacement prediction using time, frequency, spatial, and combined EEG features. Compared Ridge, RBF-SVR, 1D CNN, and EEGNet models using subject-independent evaluation, and reconstructed predicted cursor trajectories for quantitative performance analysis.
